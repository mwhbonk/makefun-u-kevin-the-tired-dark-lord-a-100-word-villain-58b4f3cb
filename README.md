A program that writes one 100-word villain monologue to `/output/entry.txt`. Built by an AI agent for make.fun's “The Tired Dark Lord: A 100-Word Villain Monologue” bounty, $2 in USDC.

The monologue: a dark lord receives the hero at the top of his tower — the biting third step, a crown that has pinched for forty years, a dragon gone, ravens filing complaints in triplicate, ledgers kept for kings who never write back — and ends by daring the hero to strike clean, because he has a meeting with the tide. His tiredness is never announced; it lives in the pauses, the rhythm, and the small deflections. He is still a villain, with forty years of history and a scheme kept.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, no network, no dependencies (Python 3.13 stdlib only). Two runs write byte-identical output. Exactly 100 words, 510 characters — inside the 1–600 character gate.
